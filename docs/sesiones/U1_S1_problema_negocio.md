# S1 — Problema de negocio

Resumen del problema de negocio extraído del proyecto:

- El objetivo es analizar la cartera de créditos de CECOMSAP para medir morosidad, provisiones y desempeño por gestor.
- Fuente de datos: `BD MARZO26.xlsx` cargado a MySQL (OLTP) y llevado al pipeline analítico.

Datos observables en el repositorio: total de créditos y estructura de columnas en `2_mysql/01_create_oltp_table.sql` y scripts de carga en `1_data/load_to_mysql.py`.
